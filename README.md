# Java Language Server (Eclipse JDT LS)

Real-time Java diagnostics, Maven/Gradle project resolution via Eclipse JDT LS

## Details
- **Identifier**: `matn.ext.java`
- **Version**: `1.0.0`
- **Category**: `languages`

## Installation
Inside Matn Editor, open the Extensions Marketplace (<kbd>Ctrl+Shift+X</kbd>), search for **Java Language Server (Eclipse JDT LS)**, and click **[Install]**.

Alternatively, install directly from GitHub:
```
https://github.com/matn-extensions/ext-java
```
